## 功能特性

- **多报纸支持** — 人民日报、学习时报、光明日报、新华每日电讯、中华读书报、文摘报、讽刺与幽默、解放军报、中国青年报
- **批量下载** — 支持最新一期、一周、一月、两月、日期区间（上限 62 天）
- **历史日期** — 支持指定历史日期下载（各报近三个月均实测可用）
- **自动合并** — 多版面 PDF/图片自动合并为单个 PDF
- **图片转 PDF** — 附带 png2pdf.py，把已保存的 PNG/JPG 报纸图片合并为 PDF
- **进度显示** — 实时下载进度与日志面板
- **记住设置** — 自动保存用户配置
- **免安装** — 提供exe单文件与免解压目录版两种发行包

## 下载安装

### 方式一：直接下载（推荐）

前往 [Releases](../../releases) 页面下载 v0.7.2，两种包任选：

| 包 | 适用场景 | 说明 |
|----|----------|------|
| `NewspaperDownloader-v0.7.2-portable.zip` | **推荐**，兼容性最好 | 解压到任意**纯英文路径**后，运行文件夹内的 `电子报下载器-v0.7.2-目录版.exe` |
| `NewspaperDownloader-v0.7.2.exe` | 便于单文件分发 | 双击即用；启动时需解压到系统临时目录，极少数环境下可能报 "Could not create temporary directory!"，此时请改用上面的 zip 包 |

> 💡 若单文件版启动报 "Could not create temporary directory!"（临时目录被占用或权限受限），改用 zip 目录版即可——目录版不做运行时自解压，不依赖系统临时目录。

### 方式二：从源码运行

```bash
# 克隆仓库
git clone <仓库地址>
cd newspaper-downloader

# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

## 使用说明

### GUI 模式

1. 选择报纸（共 9 份，见下方「支持的报纸」）
2. 选择日期（支持历史日期）
3. 选择保存目录
4. 点击下载按钮：
   - **开始下载** — 下载指定日期
   - **最新一期** — 下载最近一期
   - **最近一周 / 最近一月 / 最近两月** — 按范围批量下载（最多 62 天，约两个月）
   - **日期区间** — 任选起止日期批量下载（最多 62 天）

输出结构：`<保存目录>/<报纸名>/<YYYYMMDD>/<报纸名>_<YYYYMMDD>.pdf`

### CLI 工具

```bash
# 把已保存的 PNG/JPG 报纸图片合并为 PDF（原始图片不动）
python png2pdf.py ./downloads/人民日报/2026-09-30 -o 人民日报_20260930.pdf
python png2pdf.py 第1版.png 第2版.png 第3版.png
```

## 版本历史

### v0.7.2 (2026-10-11)
- 🔧 「最新一期」探测窗口从 7 天扩大到 **180 天（半年）**：探到最近一期即停，进度条改为确定性百分比，探测过程可随时取消

### v0.7.1 (2026-10-11)
- 🔧 修复「最新一期」仅尝试当天的问题：改为从今天起自动往前逐日探测（最多回看 7 天），找到最近一个有版面的日期再下载

### v0.7.0 (2026-10-11)
- ✨ 新增「日期区间」批量下载模式：任选起止日期逐日下载（上限 62 天，超 30 天会提示频繁网络请求风险）

- ⚡ 日期可用性检查改为轻量探测 `has_edition`：只请求第一版页面，批量检查日期时网络请求大幅减少
- 📝 文档三件套去重分工：README 面向用户瘦身，PLAN.md 重写为路线图，docs/README.md 补已知限制

### v0.6.0 (2026-09-30)

## 开发

- **环境要求**：Python 3.8+；依赖见 `requirements.txt`（PySide6、requests、pypdf、beautifulsoup4、Pillow）
- **快速构建**：

```bash
pip install -r requirements.txt pyinstaller
pyinstaller newspaper_downloader.spec --noconfirm
# 输出：dist/电子报下载器-v0.7.2.exe
```

架构说明、目录结构、添加新报纸教程、打包发布流程与排错指南，见 [开发文档](docs/README.md)；项目审计与改进计划见 [PLAN.md](PLAN.md)。
